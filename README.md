The funniest out-of-office auto-reply a houseplant would send, in 120 characters or fewer. The entry is a fern on an office desk that has not been watered since March, and the only colleague it can redirect urgent matters to is the cactus — which will not reply either.

The entry:

> Out of office until someone waters me. Last drink: March. Urgent? Ask the cactus — it won't reply either. — Fern

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` assembles the reply from its parts, checks it against the gate (UTF-8 text, 1 to 120 characters, not only white space), writes it to `entry.txt` in the output directory, then reads the file back and re-checks it before reporting success.
